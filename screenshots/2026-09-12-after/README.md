# Signal Desk — Fix 1~3 적용 후 스냅샷 (2026-09-12)

`../2026-09-12-before/` 와 같은 방법(정적 프리렌더 + `qlmanage -t -s 1600`)으로 캡처.
웹폰트는 동일하게 시스템 폰트로 대체 렌더링됐다.

## 적용한 변경
1. **기간 필터 + 연도 표기** — 피드 기본값 `최근 7일`(368건 → 50건), `최근 30일` / `전체 기간` 전환.
   기준일은 오늘이 아니라 데이터 최신일이라 수집이 밀려도 빈 화면이 안 나온다.
   올해가 아닌 항목은 `2020년 3월 16일 (월)` 처럼 연도를 붙인다.
2. **피드 검색** — 제목·요약·매체명 대상. 선택한 기간 안에서 찾고, 결과가 0건이면
   `전체 기간에서 N건 보기` 버튼으로 범위를 넓힌다.
3. **대비·마이크로텍스트·키보드** — `--body` `#8f8f8f`(3.23:1) → `#6b6b6b`(5.33:1),
   캘린더 카운트 8px → 10px 및 날짜 숫자와 겹치지 않게 배치,
   이벤트가 있는 날짜를 `<div>` → `<button>` 으로 바꿔 Tab/Enter 선택 가능 + `aria-pressed`.
